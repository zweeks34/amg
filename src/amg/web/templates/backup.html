Download a backup Database only

The database only is small, but it can't bring back the scans themselves. Your Anthropic key isn't in either: it lives in the server's settings file.

Restoring

Restoring replaces everything, so it's done on the server rather than here. Copy the zip to the server's /tmp, then run:

systemctl stop amg
amg restore /tmp/amg-backup-….zip --replace
systemctl start amg

The database it replaces is moved aside, not deleted. The zip's README says the same, and docs/DEPLOY-proxmox.md covers rebuilding the server from nothing.
